# Valo Auto Pick — Windows 11

エージェントを1人選び、毎試合のキャラ選択で自動選択・確定するWindowsアプリです。別PCでゲームを起動していても、同じRiotアカウントへのログインで接続できます。ゲーム側PCへの追加アプリ、LAN設定、ポート開放は不要です。

## 起動と使い方

1. `dist/ValoAutoPick-smooth-corners/ValoAutoPick.exe` を起動します。別PCへ移す場合は `dist/ValoAutoPick-smooth-corners-Win11-x64.zip` をコピーして展開してください。
2. 「接続設定」で「別PCから接続」を選び、右上の「Riotにログイン」を押します。
3. Riotの画面で、ゲームにログインしているアカウントのユーザー名・パスワードを入力するか、Google・Apple・Facebookの外部アカウントボタンを使用します。必要に応じて二段階認証を完了します。Cookie通知が重なる場合は右上の×で閉じてください。
4. 「エージェントを選ぶ」から画面全体に表示される一覧で使いたいキャラを1人選びます。あとで変更する場合は「エージェントを変更」を押します。
5. 「監視を開始」を押します。別PCで通常どおりマッチを開始してください。次の試合も自動で検知します。「監視を停止」を押すとピック監視と自動インキューをまとめて停止し、進行中の検索もキャンセルします。
6. ゲーム内でモードを選び、「自動インキュー開始」を押すと、ロビーに戻ったとき選択中のモードへ自動参加します。同じボタンを押すと自動参加を止め、進行中の検索もキャンセルします。見つかった試合の承諾・辞退はゲーム内で行います。

マッチを検知して選択可能になったら、設定したエージェントをすぐ選択し、選択状態を確認して確定します。自分がすでに確定済みなら操作しません。設定したエージェントが選べない場合は、試合内で手動選択してください。未解除キャラを使用可能にする機能はありません。

最小化すると通知領域に常駐します。アイコンのダブルクリックで戻ります。「監視を停止」で以後の操作を止めます。既にサーバーが受け付けた確定は取り消せません。×で監視を停止して終了します。PCのスリープ中・通信断中は動作しません。

## ログインと設定

- アカウント接続はアプリ起動ごとにログインします。パスワードをアプリの入力欄で収集・保存しません。
- ログイン画面はEdge WebView2のInPrivateプロファイルを使用し、パスワード保存と自動入力を無効化しています。Riotのほか、公式のソーシャルログイン先（Google・Apple・Facebook）のみを許可します。ログイン結果のトークンはメモリ内のみで扱います。ログアウトでブラウザーのセッション情報も消去します。
- セッションの期限が近づいたら、同じRiotのログインセッションから更新を試みます。ログインのやり直しが必要なら監視を停止して表示します。認証や二段階認証を回避する処理はありません。
- 設定は `%LOCALAPPDATA%\ValoAutoPick\settings.json` に保存します。エージェント、地域、接続方法などで、トークンは含みません。
- 「自動で監視開始」を有効にすると、接続後に監視を始めます。このPCへの接続モードではアプリ起動時に始めます。Windowsの自動起動登録は行いません。
- 同じPCで使う場合は「このPCのRiot Clientに接続」も選べます。こちらは起動中クライアントのログイン状態を利用します。
- 接続地域は通常「自動（おすすめ）」で使用してください。手動で指定する場合、日本の通常アカウントは「アジア太平洋（東京など）」です。これはアカウントの接続先であり、ゲーム内の試合サーバーを変更する設定ではありません。変更後は再ログインしてください。

## 動作環境

Windows 11 x64。配布版には.NETランタイムを同梱しています。ログイン画面には [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) が必要です。管理者権限は不要です。実行ファイルに商用コード署名はありません。

## 安全性と動作範囲
パスワードをアプリ側で保存しない、外部通信の証明書を検証する、ログイン先をRiotと公式ソーシャルログイン先に限定する、ログイン応答のstateを検証する、トークンをログに出さない対策を実装しています。ローカル接続モードだけは、固定の127.0.0.1宛てRiot Clientの自己署名証明書を許可しています。

ゲームのメモリ操作、DLL注入、アンチチート回避は行いません。自動インキューはボタンで明示的に開始し、パーティーリーダーで、選択モードが参加可能なロビー状態に限って参加します。検索中に停止するとキュー離脱を要求します。マッチ成立後の承諾・辞退とモード変更はゲーム内で行ってください。キュー状態の確認は8秒間隔です。ピック監視は通常250ミリ秒間隔で、検知後は同じ監視サイクル内に選択・確定まで続けて実行します。通信失敗時は間隔を延ばし、429応答ではRetry-Afterに従います。再試行回数には上限があります。

## Visual Studioで開く

プロジェクト直下の `ValoAutoPick.sln` を開きます。アプリのソースは `src/ValoAutoPick/` にあります。Visual Studio 2022以降と.NET 9 SDK、Windows Formsの開発機能が必要です。

## 開発・ビルド

.NET 9 SDKで `powershell -ExecutionPolicy Bypass -File .\build.ps1` を実行します。確認後に `dist/ValoAutoPick-smooth-corners-Win11-x64.zip` を生成します。エージェント画像は `src/ValoAutoPick/Assets/Agents/` に埋め込み済みです。更新する場合は `py -3.11 -m pip install Pillow` の後、`py -3.11 tools/fetch_agents.py` を実行します。

資料: [API調査リファレンス](https://github.com/techchrism/valorant-api-docs)、[キャラ情報API](https://valorant-api.com/)、[Riotの開発者向け方針](https://developer.riotgames.com/docs/valorant)。
